## 1. 阶段目标与验收门槛

**目标**：Agent 从"只读知识库问答"升级为"可调用工具执行结构化查询"；知识库从"手动上传"走向"自动摄入"；评估与合规闭环。

**P2 验收标准**：

1. 工具调用：Agent 可注册/调用工具（内置只读 SQL 工具示例），图内 tools 轨迹可观测（FR-25）；
2. 反馈回流：点踩样本一键沉淀为评估用例（FR-40），回归门禁可消费新用例；
3. Connector：目录/网盘定时扫描自动摄入（FR-08），复用摄入管道，失败可重试；
4. 脱敏：敏感词/正则规则在摄入与回答两个环节生效（FR-36），审计记录命中；
5. 术语表：同义词映射参与改写/检索（P1_PLAN 2.2 遗留），召回提升可测；
6. GraphRAG（可选试点）：图结构辅助多跳问答，成本可控、可回退。

## 3. W1 工具调用详细拆分（FR-25）

| 任务 | 说明 | 依赖 |
|---|---|---|
| Tool/ToolRegistry | 工具注册框架：name/description/args_schema/async fn；describe 供提示词 | — |
| 内置工具 query_documents | 只读 SQL 查询 documents 元数据表；约束：仅 SELECT、单语句、表白名单、强制 LIMIT、结果截断 | ToolRegistry |
| plan_tools 节点 | 路由后 LLM 判断是否调用工具（与现有 JSON 输出模式一致），执行结果入 state | 框架 |
| 图布线 | route_intent → plan_tools → decompose；chat/clarify 仍直拒答 | 节点 |
| 生成注入 | tool_results 成功项追加为"结构化数据"上下文块（不占引用编号） | assemble |
| 配置 | agent_tools_enabled / tools_max_rows 开关 | config |
| 测试 | SQL 安全约束、工具调用（SQLite 真实执行）、节点、图集成回归 | — |

**安全边界**（只读 SQL 工具）：去注释 → 拒多语句 → 仅 SELECT → 表名白名单（documents）→ 强制 LIMIT → 值截断。未来接入真实业务表时，仅需扩展白名单 + 列级权限评审。

## 4. 新增需求（2026-08-17 追加）

**RBAC 扩展**（用户提出，已实施，详见 [RBAC_PLAN.md](./RBAC_PLAN.md)）：

- 角色三档：`super_admin`（超级管理员，全权）/ `admin`（部门管理员，负责 N 个部门）/ `user`（普通用户，仅问答）；
- 文档管理管理员化：普通用户无文档管理入口（前端隐藏 + API 403）；知识库内容由管理员统一维护；
- 超级管理员可在用户管理页创建用户、分配角色、指定部门管理员的负责部门（AdminDepartment 表，覆盖式分配）；
- 权限统一入口 `user_visible_departments()`：QA 检索过滤与文档管理共用，避免权限判断散落；
- 防自锁：不能修改自己角色/停用自己；必须保留至少一个 super_admin；
- 存量迁移：role='admin' → 'super_admin'（保权不缩水），再按需降级为部门管理员并分配部门。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 工具暴露内部数据库 | 数据泄露 | 只读 + 白名单 + LIMIT + 结果截断；P2 默认仅元数据表 |
| LLM 误触发工具拖慢回答 | 延迟增加一次 LLM 调用 | 提示词强约束 + agent_tools_enabled 开关可整体关闭 |
| 工具结果影响评估基线 | 回归波动 | 评估脚本可禁用工具开关（env），基线对比口径不变 |
| GraphRAG 成本不确定 | 周期拉长 | 试点独立评审，不阻塞主线 |
